# Link Ai

Project-first networking app for AI builders.

Link Ai helps people working in AI (builders, founders, freelancers, learners) connect based on:

- What they’re building
- What they need
- Who they want to meet

The goal is useful introductions and collaboration — not a noisy social feed.

## MVP (planned)

- Auth + profile onboarding (skills, tools, intent)
- “Build” cards (project showcase feed + details)
- Builder discovery + search/filters
- Connection requests (accept/reject) + 1:1 chat after acceptance
- AI helpers: intro message generator + build feedback generator

## Tech stack (target)

- Flutter app (this repo)
- Clean Architecture, feature-first modules (planned)
- Backend: Supabase or Laravel API (TBD)

## Getting Started (Flutter)

Install Flutter, then:

```bash
flutter pub get
flutter run
```

Run tests:

```bash
flutter test
```
